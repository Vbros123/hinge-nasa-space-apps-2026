# Limitations

HINGE covers one provisional demonstration area. The archive supports discrete tested parameter sets and 40 overlapping historical three-year windows. It provides conditional screening results, and the crop assumptions and site's agricultural applicability require independent local review.

NASA POWER is gridded weather. SSURGO storage is survey-derived with missing mapped component mass. HLS NDVI describes 2025 vegetation and has no rotation attribution. Calendar feasibility uses statewide or regional evidence and assumed management. A leader change across tested cases does not specify an interpolated threshold.

The engine omits runoff and does not forecast yield, profit, erosion or future weather. See the [integration report](INTEGRATION_REPORT.md) for additional context.

Reviewers can inspect the [model source and documentation](../science-backend/README.md) and generate the mock test fixture locally. Exact scientific replay requires the original cached environmental bundle.
