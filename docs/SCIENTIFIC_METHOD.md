# Scientific method

The Phase 3 engine computes FAO-56 reference evapotranspiration from gridded weather, estimates crop ET demand using assumed crop coefficients and schedules, and tracks a daily soil-water bucket. It compares three rotations in identical historical weather windows and measures changes across individual parameter alternatives.

Calendar feasibility is calculated under documented management and phenology assumptions. The comparison shows unmet crop-water demand and rainfall exposure under modeled low living cover as independent objectives. Historical paired differences match the same window and parameter set. For annual values and metric definitions, see the [integration report](INTEGRATION_REPORT.md).
