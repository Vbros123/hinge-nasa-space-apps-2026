Largest change in modeled unmet demand from any initial-condition choice: **0.0000 mm** (block totals are roughly 800-1000 mm). Largest change in modeled deep drainage: **50.0 mm**, which equals the difference in starting storage (25 to 50 mm): the extra starting water simply overflows once the bucket refills. On this synthetic weather (wet winters, Jan-Apr fallow with low demand) the starting condition is forgotten within weeks for unmet demand, so spin-up is immaterial for that metric and shifts drainage one-for-one. This does NOT show the same holds for real Johnston County weather, where a dry preceding autumn could matter more; re-run this script on real data.

## 6. Remaining limitations

- Parquet ingestion untested if pyarrow is absent (see skipped tests).
- Kc, stage lengths, fallow and cover parameters are generic or assumed; see crop_water_parameter_validation.md.
- Soil storage values are illustrative until SSURGO-derived values are supplied.
